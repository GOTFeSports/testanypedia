# Anypedia

Энциклопедия полупрофессиональных турниров Dota 2 с ограничением по ПТС. Статический сайт без бэкенда (GitHub Pages / Vercel). Есть светлая и тёмная тема (кнопка слева внизу, выбор запоминается). Основной цвет — зелёный (переменная `--accent` в `css/style.css`).

Сейчас есть страницы турниров: список и страница турнира в стиле Liquipedia. Команды и игроки — позже.

## Структура

```
assets/dota2.png          ← логотип команды по умолчанию (замените на свой)
tournaments/
  index.json              ← генерируется (npm run build), руками не править
  anylvl-cup/             ← один турнир = одна папка (адрес: /anylvl-cup)
    information.json      ← информация о турнире (инфобокс, призы, трансляции)
    roster.json           ← команды и составы
    result.json           ← итоги: места и этапы (группы, швейцарка, сетки)
    logo.png              ← логотипы (необязательно, пути указываются в json)
```

## Что на сайте

- **Главная:** статистика, ближайший (или идущий) турнир с быстрыми ссылками на разделы, виджет «Матчи» (Предстоящие / Завершённые), победители, остальные турниры по статусам. Всё берётся из `tournaments/index.json`, который собирает `npm run build` — поэтому после любых изменений в данных его нужно запускать.
- **Страница турнира:** сверху участники и призовые места рядом с инфобоксом, ниже на всю ширину этапы (группы, швейцарка, сетки) и трансляции. Адрес турнира — `/<slug>`, ссылка на раздел — `/<slug>/<раздел>`, например `/anylvl-cup/prizes` (разделы: `participants`, `prizes`, `stage-0`, `stage-1`, …, `streams`).
- **Сетки и таблицы всегда помещаются по ширине без горизонтальной прокрутки:** сетка плей-офф масштабируется под экран, а на узких экранах превращается в список раундов; в швейцарке на узких экранах прячутся колонки раундов (матчи остаются в списке под таблицей).
- Кнопка темы — слева внизу, стрелка «наверх» — справа внизу.

## Добавить турнир

1. Создать папку `tournaments/<slug>/` с файлами (`roster.json` и `result.json` можно добавить позже).
2. `npm run build` — обновит `tournaments/index.json` и предупредит об ошибках (команда есть в результатах, но нет в составе; не найден логотип; матч ведёт в несуществующий матч; неизвестный тип этапа).
3. Закоммитить.

Локальный просмотр: `npm run serve` → http://localhost:8080 (свой маленький сервер с чистыми ссылками; `python -m http.server` для них не подходит).

Имя папки турнира нельзя брать из занятых сайтом: `assets`, `css`, `js`, `tools`, `tournaments` (`npm run build` предупредит). Старые ссылки вида `#/t/<slug>` автоматически перенаправляются.

Для Vercel нужен `vercel.json` из репозитория: он собирает индекс и отдаёт `index.html` на любой адрес (`rewrites`) — без этого `/<slug>` при прямом заходе даст 404.

```json
  "series": "AnyLvL Cup",
  "organizer": "AnyLvL x GOTF eSports",
  "sponsors": ["Спонсор"],
  "status": "upcoming | live | finished",
  "type": "online | lan | hybrid",
  "location": "СНГ",
  "game": "Dota 2",
  "version": "7.41",
  "date_start": "2026-11-14",
  "date_end": "2026-11-15",
  "format": ["Групповой этап ...", "Плей-офф ..."],
  "pts_cap": 20000,
  "prize_pool": "10 000 ₽",
  "description": "Текст о турнире",
  "links": { "challonge": "", "rules": "", "discord": "", "telegram": "", "vk": "" },
  "prizes": [
    { "place": 1, "prize": "5 000 ₽" },
    { "place": 3, "place_to": 4, "prize": "Мерч" }
  ],
  "streams": [ { "lang": "ru", "platform": "twitch", "url": "https://…" } ]

```
Все поля необязательны, пустые не показываются. `pts_cap` показывается как «Лимит» (только в инфобоксе и на карточке турнира).
`prizes` — какие места призовые: по умолчанию в таблице видны только они, остальные места раскрываются кнопкой.

## roster.json

```json
{ "teams": [ {
  "name": "Команда",
  "logo": "teams/team.png",
  "status": "invited | qualified | registered",
  "qualifier": "Открытая квалификация · 1 место",
  "players": [ { "nick": "player" } ],
  "coach": { "nick": "coach" },
  "subs":  [ { "nick": "sub" } ]
} ] }
```
- Первые пять `players` получают позиции 1–5 по порядку (или задайте `pos`).
- `logo` — путь относительно папки турнира или полный URL. Если не указан, берётся `assets/dota2.png`.
- Запасные игроки (`subs`) показываются во вкладке «Запас» на карточке команды; если их нет, вкладок нет.

## result.json

```json
{
  "placements": [
    { "place": 1, "team": "Команда" },
    { "place": 5, "label": "5–6", "team": "Другая команда" }
  ],
  "stages": [ ...этапы по порядку... ]
}
```
Названия команд везде должны совпадать с `roster.json`. Старый формат (`groups` + `playoffs` вместо `stages`) тоже читается.

### Типы этапов (`stages[].type`)

**`swiss` — швейцарская система** (до N побед; пример — до трёх):
```json
{ "type": "swiss", "name": "Швейцарская система", "advance": 8,
  "teams": ["A", "B", "..."],
  "rounds": [ { "name": "Раунд 1", "matches": [ { "team1": "A", "team2": "B", "score1": 2, "score2": 0, "date": "2026-12-05" } ] } ] }
```
Таблица (W-L, карты, Buchholz, результат каждого раунда с логотипом соперника) считается автоматически. Buchholz = сумма (победы − поражения) всех соперников. `advance` — сколько команд проходят дальше (подсветка).

**`single_elim` / `double_elim` — сетки на выбывание:**
```json
{ "type": "double_elim", "name": "Плей-офф",
  "rounds": [
    { "name": "Верхняя сетка · полуфиналы", "bracket": "upper",
      "matches": [ { "id": "ub-sf-1", "team1": "A", "team2": "B", "score1": 2, "score2": 0, "next": "ub-f" } ] },
    { "name": "Нижняя сетка · раунд 1", "bracket": "lower", "matches": [ ... ] },
    { "name": "Гранд-финал", "bracket": "final", "matches": [ ... ] },
    { "name": "Матч за 3 место", "bracket": "third", "matches": [ ... ] }
  ] }
```
`bracket`: `upper` (по умолчанию) · `lower` (нижняя сетка под верхней) · `final` (колонка справа) · `third` (матч за 3 место, под финалом). `next` — id матча, куда проходит победитель; по нему рисуются линии.

**`groups` — групповой этап.** Формат у каждой группы свой (`format`):
```json
{ "type": "groups", "name": "Групповой этап", "groups": [
  { "name": "Группа A", "format": "round_robin", "advance": 2, "teams": ["A","B","C","D"],
    "matches": [ { "team1": "A", "team2": "B", "score1": 2, "score2": 0, "date": "2026-11-14" } ] },
  { "name": "Группа B", "format": "double_elim", "rounds": [ ... как в сетках ... ] },
  { "name": "Группа C", "format": "single_elim", "rounds": [ ... ] },
  { "name": "Группа D", "format": "swiss",       "teams": [ ... ], "rounds": [ ... ] }
] }
```
`format`: `round_robin` (по умолчанию; таблица мест и кросс-таблица считаются сами из `matches`), `single_elim`, `double_elim`, `swiss`.

Если нет этапов, можно дать простой список `"matches": [{ "round": "Финал", "team1": …, "team2": …, "score1": …, "score2": … }]`.

> Турниры `anylvl-cup`, `anylvl-cup-2` (предстоящий) и `swiss-test` в репозитории — **тестовые данные** для проверки вёрстки. Замените или удалите папки и снова запустите `npm run build`.
